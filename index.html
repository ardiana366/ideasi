Petunjuk Penggunaan

Cara mengoperasikan papan Ideasi

Tulis Ide Baru, Warna & Hapus

Double Tap pada area kosong untuk memunculkan oval baru. Klik ide untuk memunculkan opsi warna, stempel Ceklis (✓) / Silang (✗), serta tombol Hapus Ide.

Pilih & Geser Bersama (Multi-Select)

Klik/tap pada oval untuk memilihnya, lalu seret salah satu untuk memindahkan semuanya bersamaan. Klik sekali di area kosong untuk membatalkan pilihan.

Hubungkan, Pindah Garis & Hapus Garis

Tarik tepi oval untuk menghubungkan. Klik 1x pada garis untuk memunculkan tombol ✕ (Hapus Garis) dan titik handle bulat untuk memindahkan sambungan ke sisi manapun (atas, bawah, kiri, kanan).

Zoom & Backup JSON

Gunakan pinch 2 jari atau scroll mouse untuk zoom. Klik tombol Export untuk menyimpan file JSON dan Import untuk memuat kembali.
