Petunjuk Penggunaan

Cara mengoperasikan papan ide whiteboard

Tulis Ide Langsung di Oval

Double Tap pada area kosong untuk memunculkan oval baru dan langsung mengetik. Double tap pada teks oval untuk mengedit.

Pilih & Geser Bersama (Multi-Select)

Klik/tap pada oval untuk memilihnya, lalu seret salah satu untuk memindahkan semuanya bersamaan. Klik sekali di area kosong untuk membatalkan pilihan.

Koneksi Kiri-Kanan & Pindah Garis

Tarik tepi oval untuk menghubungkan. Klik 1x pada garis untuk memindahkan ujung sambungannya. Saat garis aktif terpilih, pembuatan garis baru dari oval dinonaktifkan sementara.

Zoom & Backup File

Gunakan pinch 2 jari untuk zoom. Klik tombol Export untuk menyimpan file JSON dan Import untuk memuat kembali.
